# python-almost_a_circle

A review of core Python concepts (imports, exceptions, classes, private
attributes, getters/setters, class/static methods, inheritance, unittest,
file I/O) built by implementing `Base`, `Rectangle`, and `Square` classes,
along with JSON serialization/deserialization.

## Files

- `models/base.py` - the `Base` class, parent of all other classes.
- `models/rectangle.py` - the `Rectangle` class (inherits from `Base`).
- `models/square.py` - the `Square` class (inherits from `Rectangle`).
- `tests/` - unittest test suite.
