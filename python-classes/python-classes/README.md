# Python - Classes and Objects

## Description
This project is an introduction to Object Oriented Programming (OOP) in
Python 3. It covers the fundamentals of classes and objects: how to define
a class, how to create instances, the difference between an attribute and
a property, public/protected/private attributes, the `self` keyword, the
`__init__` method, data abstraction/encapsulation/information hiding, and
how Python resolves attribute lookups on objects and classes.

## Learning Objectives
- Why Python programming is awesome
- What is OOP
- "First-class everything"
- What is a class vs an object/instance
- What is an attribute, and how public/protected/private attributes work
- What is `self`
- What is a method
- What is the `__init__` method and how to use it
- What is Data Abstraction, Data Encapsulation, and Information Hiding
- What is a property, and how it differs from a plain attribute
- The Pythonic way to write getters and setters
- How to dynamically add attributes to instances
- How to bind attributes to objects and classes
- What `__dict__` is and what it contains
- How Python looks up attributes on objects/classes
- How to use `getattr`

## Requirements
- Editors allowed: `vi`, `vim`, `emacs`
- Files interpreted on Ubuntu 20.04 LTS with `python3` (version 3.8.5)
- All files end with a new line

- All files are executable
- Every module, class, and function/method has a docstring
