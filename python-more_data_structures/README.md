# Python - More Data Structures: Set, Dictionary

## Description
This project covers Python sets and dictionaries: set operations
(intersection, symmetric difference), dictionary key/value manipulation,
sorting dictionary keys, and functional tools like map and lambda
functions.

## Requirements
- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- Every file starts with #!/usr/bin/python3, ends with a newline, and is
  executable
