# python-network_0

## Description
This project covers the basics of HTTP: URLs, requests, responses, headers,
methods, status codes, and cookies, using Bash scripts with `curl` to
interact with a local web server.

## Learning Objectives
- What a URL is and how to read one
- What HTTP is, and what HTTP requests/responses are
- What HTTP headers, methods, and status codes are
- What an HTTP Cookie is
- How to make requests with `curl`
- What happens when you type `google.com` in your browser

## Tasks

| File | Description |
| --- | --- |
| `0-body_size.sh` | Displays the size in bytes of the body of the response to a URL |
| `1-body.sh` | Displays the body of a GET response, only if the status code is 200 |
| `2-delete.sh` | Sends a DELETE request and displays the body of the response |
| `3-methods.sh` | Displays all HTTP methods the server accepts |
| `4-header.sh` | Sends a GET request with a custom header `X-HolbertonSchool-User-Id: 98` and displays the body |
| `5-post_params.sh` | Sends a POST request with `email` and `subject` params and displays the body |
