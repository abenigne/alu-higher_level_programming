# Python - Test-Driven Development (TDD)

This repository contains tasks covering Test-Driven Development in Python using `doctest` and `unittest`.

## Tasks Overview
* **0. Integers addition**: Function `add_integer` that adds two integers.
* **1. Divide a matrix**: Function `matrix_divided` that divides all elements of a matrix by a divisor.
* **2. Say my name**: Function `say_my_name` that prints full names.
* **3. Print square**: Function `print_square` that prints a `#` square of given size.
* **4. Text indentation**: Function `text_indentation` that formats strings around `.`, `?`, and `:` punctuation.
* **5. Max integer - Unittest**: Unittests for `max_integer`.
